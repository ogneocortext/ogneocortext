# NeoCortext

Independent developer. I've been working online since 2008, when I sold my first website template through Craigslist. I was mentored by two partners (a relationship dating to 2004) and built two short-lived websites with them — a first site in 2010, then a furniture site in 2017, monetized with display ads and Amazon affiliate links, that ran for a few months. I ran a freelance marketplace business at ~$2,000/month at its peak, drove professionally across the Phoenix metro — and I now build software by directing AI coding agents: I write the specs and plans, set the verification gates, review what lands, and keep the reasoning in the commit history.

## What I'm building

- **[Native Media AI Studio](https://github.com/ogneocortext/Native-Media-AI-Studio)** — a local music-video production platform. React + TypeScript + Remotion front end, FastAPI backend, ComfyUI generation, GPU audio analysis, all targeted at an 8 GB VRAM home workstation. 600+ commits, a written decision log (D1–D40+), and checker scripts that gate every push.
- **[Space Analyzer Pro](https://github.com/ogneocortext/space-analyzer-pro)** — a cross-platform disk-space analyzer with a Rust core, a native WinUI 3 GUI, and a local Ollama-powered assistant that shows deletion impact before you delete.

## How I work

- **Planner/executor split:** my specs and task files carry the decisions; coding agents (rotating models and tools) execute them. An item without a written plan isn't ready to build. On a typical day I run 2–3 agents concurrently — research, planning, and execution roles in parallel — nearly every day.
- **Commits are documentation:** messages carry the "why," so `git log` is a guidance channel for whoever — or whatever — picks the repo up next.
- **Verification over vibes:** model and tool reliability is tracked from an evidence log, not benchmarks; gates run before anything is called done.
